# SNS文章收藏夾 V3.2.3

**SNS文章收藏夾 / SNS Bookmark / by littlemonkey805**

**V3.2.3**（以 V3.2.2 build 2026-11-13 13:20 為基底；build 2026-11-13 14:05）：修正不同篩選條件無法交集疊加——點資料夾、標籤（面板或卡片）、未讀時不再清掉其他篩選；「🏷️ 標籤」按鈕選了標籤時只亮起來、不再接標籤名稱；「目前篩選」每個條件可按 × 單獨取消；標籤可以複選（同時有這些標籤才顯示）。**Code.gs 免更新、環境變數不用改、資料格式沒變**。

**V3.2.2**（以 V3.2.1 complete-6 build 2026-11-13 05:10 為基底；build 2026-11-13 13:20）：目前篩選狀態列（電腦在「收合」右邊、手機在待回顧區上方；固定一行、放不下收進「…更多」、沒有篩選就隱藏）；手機待回顧區更精簡；「分類」統一改為「資料夾」（「未分類」→「無資料夾」，待回顧選單→「回顧類型」）；Instagram 搜尋文字同一份回應順便帶入；「原貼文發布日」提示移到日期框下方。**Code.gs 免更新、環境變數不用改、資料格式沒變**。

**V3.2.1**（以 V3.2.0 complete-5 build 2026-11-13 03:10 為基底；build 2026-11-13 05:10）：十個平台一律優先偵測發文帳號，搜尋文字、原文發布日期分開嘗試（新增發布日期自動帶入與 `auto.pub` 手動保護）；指定日期回顧顯示「發布／收藏 N 年」；卡片「刪除　編輯」（編輯最右側）；網址空白畫面照留、程式忽略。**Code.gs 免更新、環境變數不用改、沒有新增試算表欄位**。詳見 `CHANGELOG.md`、`TEST_REPORT.md`、`RESEARCH-V3.2.0.md` 第七節。

**V3.2.0**（以 V3.1.0 build 2026-11-12 15:23 為基底）：九個平台（Bilibili、YouTube、抖音、TikTok、微博、Facebook、Threads、X、Instagram）自動帶入「發文帳號」與「貼上的文字」，統一失敗處理與手動內容保護；Facebook 手機分享網址無法確認重複時一定提醒。收藏資料新增一個隱藏的選填欄位 `auto`；新增 `api/_lib/info.js`；**Code.gs 免更新、環境變數不用改**。

**V3.1.0**（以 V3.0.0 build 2026-11-12 02:41 為基底）：TikTok／抖音／微博／Bilibili／Facebook 網址識別與重複比對修正、手機整段分享文字自動擷取網址（原文保留）、新的「無法確認是否收藏過」提醒、收藏可加入多個分組（新增／編輯視窗可選分組）、待回顧日期改成每年的月／日、標籤輸入區自動換行。資料格式新增三個**選填**欄位（`gs`、`share`、`ck`），舊資料不用轉換；`api/resolve.js` 擴充；**Code.gs 免更新、環境變數不用改**。詳見 `CHANGELOG.md` 的 V3.1.0 一節。

- **重複比對**：TikTok 影片 ID、抖音影片 ID（含 `modal_id`）、微博貼文 ID（英數代碼與數字 ID 互通）＋影片 FID、Bilibili BV 號（忽略語系路徑與追蹤參數）、Facebook 貼文／影片 ID。微博貼文與影片頁靠平台公開的貼文資料建立關聯。

- **多分組**：新增／編輯視窗新增「分組」欄位（可複選、可不選）；卡片幾個分組就幾個顏色方塊；舊版單一分組資料直接相容。
- **待回顧日期**：只選月／日，每年同一天回顧。
- **標籤輸入區**：標籤多時自動換行，輸入框與清除鈕放不下就移到下一行。

## 這一版要另外設定什麼？（V2.8.0 起）
