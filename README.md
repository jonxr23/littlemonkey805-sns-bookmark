# SNS文章收藏夾 V2.10.0

**SNS文章收藏夾 / SNS Bookmark / by littlemonkey805**

V2.10.0 以 V2.9.0 安裝包為唯一基底：資料夾與分組排序（A→Z／自訂拖曳）、歷史公告收合、圖示與文字調整、手機工具列兩排、浮動按鈕配色與陰影、電腦特大版面、公告標題。V2.9.0 以 GitHub `main` 的 V2.8.3（commit `ae7f77e`）為唯一基底：全站介面大小、圖片原檔保留提示、明細標籤篩選、明細回到最上方、「已下載」快速篩選、側邊欄重新設計、頂部／側邊欄固定與卡片區獨立捲動、備份還原說明。V2.8.3 以 V2.8.2 為唯一基底：分組視窗加「管理分組」入口、手機新增資料夾一步開啟、管理分類不自動彈鍵盤、欄位名稱與發文帳號提示、手機漢堡選單品牌標頭、側邊欄作者署名，並修正「預設主題上傳背景圖沒有反應」；V2.8.2 以 V2.8.1（含小確的平台調整）為基底，修正「除了表格以外的檢視全部空白」、防止產生空白收藏，並加回 PTT 發布日推算與 Facebook 帳號偵測；V2.8.1 以 V2.8.0 完整版為基底，將預設主題改為「品牌桃」，並依最終需求把 Facebook、Dcard、PTT 改為使用者自行新增的平台；V2.8.0 以 V2.7.0 完整安裝包為基底（V2.7.0 ← V2.6.0 ← V2.5.0 ← V2.4.0 ← V2.3.0 ← V2.2.0），V2.7.0 六大功能全部保留。
Google 登入、帳號綁定、Google Drive／Sheets 同步、圖片／GIF／外部網址、收藏資料格式都沒有改；一般使用者的 OAuth 權限仍然只有 `drive.file`；沒有新增任何環境變數。
從正式版 V2.6.0 升級時，**必須先完成管理試算表升級**：更新 Apps Script（V2.8.0 的 Code.gs；V2.8.1～V2.10.0 都沒有再改）、執行 `setupAdminSheet`，並把 Google 表單回覆連到管理試算表。確認六個工作表都完成後，才部署網站到 Production（見 `DEPLOY.md` 第三、四節及 `admin-setup/ADMIN_SETUP.md` 最後的「V2.8.0 更新步驟」）。

## V2.10.0 重點

- **排序**：資料夾面板、分組清單上方各有「A→Z｜自訂排序」。自訂排序時拖曳 ⠿（電腦按住、手機長按）調整順序；資料夾只在同一層之間移動，不會換父資料夾。兩邊各自保存，透過雲端同步到每台裝置；不改任何收藏。
- **公告**：最多顯示 5 則，其餘收在「⌄ 歷史公告（N）」；彈窗高度固定，清單在裡面捲動。標題「📢 公 告 ：(小猴的廢話時間🐵)」。
- **文字與圖示**：🏠 最上層、📚 分組、📁 選擇資料夾、🏷️ 標籤、✕ 清除篩選。
- **手機工具列**：第一排 搜尋／日期／標籤，第二排 全部平台／批次／清除篩選／新增。
- **浮動按鈕**：「⋯」往左 16px，顏色跟主題（主按鈕＝強調色，＋新增／↑Top＝強調色與底色各半混色），陰影變小。
- **電腦特大**：頂部第一排維持原本大小，側邊欄整塊一起捲動。
- **Code.gs 免更新**；收藏資料格式、Google 同步、API、OAuth、環境變數都沒有改。

## V2.9.0 重點

- **介面大小**：設定 ▾ →「🔍 介面大小」，小 85%／中 100%（預設）／大 135%／特大 150%。文字、按鈕、輸入框、卡片與間距、圖示、彈出視窗、側邊欄一起調整（不是用 zoom 放大整頁），只存在這台裝置。
- **側邊欄**：最上面「全部／未讀／已下載」三顆等寬按鈕；中間固定五個入口「資料夾、未分類、加星號、分組、管理分組」；下方共用面板顯示「資料夾管理」或「分組清單」（同時只顯示一種，清單在面板內捲動）；最底部固定作者與版本。
- **固定版面**：頂部整個工具列（手機版是多排）與展開的設計面板固定在上方，側邊欄固定，只有卡片區上下捲動。
- **收藏明細**：點標籤會關閉明細並篩選該標籤；每次打開都從最上方開始。
- **圖片**：JPG、PNG 優化後沒有變小時，統一顯示「圖片原檔已保留（容量，優化處理後未能減少容量）」。
- **備份與還原**：「從備份檔還原」下方列出三條還原規則（已和實際程式核對）。
- **Code.gs 免更新**；收藏資料格式、Google 同步、API、OAuth、環境變數都沒有改。

## V2.8.3 重點

- **背景圖修正**：以前在品牌桃、暖米綠、深色、簡約按「上傳背景圖」沒有反應，原因是程式只在「自訂」主題才顯示背景圖（圖片其實有上傳成功）。現在四種預設主題都能用，而且**不會切換成自訂主題**，配色完全不變；預設主題共用一張背景圖，和自訂主題的背景圖分開保存。
- **介面**：分組視窗「取消卡片分組｜管理分組」、手機側邊欄＋新增直接開完整的新增資料夾視窗、手機打開管理分類與新增資料夾時不會自動彈出鍵盤（電腦維持自動聚焦）、「備註（其實是標題😂）」、發文帳號提示、手機漢堡選單頂端加小猴品牌標頭、側邊欄底部加作者署名。
- **Code.gs 免更新**：和 V2.8.2 相同。這次沒有改 API、資料格式、OAuth、環境變數。

## V2.8.2 重點

- **修正**：資料裡只要有一筆缺少平台的收藏，卡片、列表、圖片牆、相簿、時間軸、看板就會全部空白（只有表格正常）。現在會正常顯示，殘缺的那筆卡片上有 ⚠️ 提示，可以打開後刪除。
- **防止再發生**：對已經被刪除（或還沒同步到這台裝置）的收藏按 ★／已讀／備註／分組，改為顯示提示，不再把它存成只有一個欄位的空白收藏。
- **加回**：PTT 文章網址自動推算發布日、Facebook 貼文網址自動偵測發文帳號。只看網址，Facebook／PTT 仍不是內建平台。
- **Code.gs：免更新（V2.8.0～V2.8.3 相同）；但正式環境是 V2.5.0，這次上線仍必須首次更新並執行一次 `setupAdminSheet`。**

## V2.8.1 重點

- 全新使用者第一次開啟就是「品牌桃」；舊裝置原本的「暖米綠」（舊版自動存的）一次性轉為品牌桃，深色／簡約／自訂不動；之後使用者自己選的主題都會保留。
- **預設平台**：系統內建平台只保留 IG、Threads、X、YouTube。Facebook、Dcard、PTT 不再預設出現，也不會自動辨識；第一次貼上這些網站的網址時，請從「新增平台」建立，建立後才會記錄該網域並自動辨識。
- Code.gs 與 V2.8.0 相同（見上方 V2.8.2 重點）。

## 這一版要另外設定什麼？（V2.8.0 起）

**需要（管理者，一次）**：
1. 把 `admin-setup/Code.gs` 貼進管理試算表的 Apps Script，執行一次 `setupAdminSheet`（新增「公告管理」）。
2. 在 Google 表單把回覆目的地改成 `SNS_Bookmark_Admin`，再執行一次「重新套用格式」（產生「意見回饋紀錄」）。

**不需要**：新增或修改 Vercel 環境變數、Google Cloud Console、OAuth 範圍、Service Account、重建管理試算表、新增 Apps Script 觸發條件；使用者的 Google Drive／`SNS_Bookmark_Data` 完全不動。

**資料格式**：收藏資料沒有任何變更；公告與意見回饋只存在管理試算表。

**品牌素材**：淺色／深色／自訂背景 Logo 依你確認的對應（深色與自訂背景刻意共用同一張）。`brand-assets/` 內容與來源見 `brand-assets/素材清單.md`。

升級步驟請看 `DEPLOY.md`，所有修改請看 `CHANGELOG.md`，測試結果請看 `TEST_REPORT.md`。
